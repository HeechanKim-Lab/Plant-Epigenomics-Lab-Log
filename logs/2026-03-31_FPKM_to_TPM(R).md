# Normalization: FPKM to TPM Conversion (R)
**Date:** March 31, 2026
**Project:** Plant-Epigenomics-Lab-Log

## Overview
To ensure accurate cross-sample comparability of gene expression, the raw FPKM (Fragments Per Kilobase Million) values generated by `StringTie` were converted into TPM (Transcripts Per Million). This step was executed in R by directly parsing the transcript-level data tables (`t_data.ctab`) within the `ballgown` output directory.

## 🛠 R Pipeline Architecture

### 1. Environment Setup
Set the working directory to the data root and verified the pathing to the Ballgown output files to ensure the script runs smoothly across different environments.
```R
setwd("~/Desktop/at_pr/at_data")
file.exists("ballgown/R1-1_WT/t_data.ctab")
```

### 2. The Conversion Function
Created a targeted function (`get_tpm_safe`) to read the `.ctab` file for a given sample, extract the FPKM column, and apply the normalization formula:
$$TPM_i = \left( \frac{FPKM_i}{\sum FPKM} \right) \times 10^6$$

The function retains both the unique `t_name` (transcript ID) and `gene_id` to ensure precise downstream mapping without duplicate row errors.

### 3. Vectorized Execution & Matrix Merging
Used `lapply` to execute the conversion function across all six replicates (WT and Cond) simultaneously. The resulting list of data frames was then recursively joined using `Reduce` and `merge`.

* **Merge Keys:** `c("t_name", "gene_id")`
* **Performance:** The 1-to-1 join utilizing unique transcript IDs completed the operation almost instantaneously.

### 4. Output
The final joined matrix was exported for use in exploratory data analysis (EDA) and visualization.
* **Output File:** `arabidopsis_transcript_tpm_matrix.csv`
