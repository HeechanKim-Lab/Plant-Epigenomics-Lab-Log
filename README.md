# Plant-Epigenomics-Lab-Log 🌱

This repository serves as a research log for my work as an undergraduate researcher in the Plant Immunity & Epigenetics Laboratory. It documents my journey into computational biology, specifically focusing on RNA-seq analysis and epigenetic regulation.

## 🧬 Current Focus: RNA-seq Tuxedo Protocol
I am currently processing **Arabidopsis thaliana** lab data and tutorial datasets to master the "New Tuxedo" pipeline.

### Data Overview
* **Sample Types:** Wild Type (WT) and Conditioned (Cond) Arabidopsis samples.
* **Format:** Paired-end RNA-seq (FASTQ/BAM).
* **Goal:** Identify differentially expressed genes (DEGs) and perform transcript assembly to understand plant immune responses.

### Tools & Pipeline
1.  **Alignment:** `HISAT2` for mapping reads to the reference genome.
2.  **Processing:** `Samtools` for sorting and indexing BAM files.
3.  **Assembly:** `StringTie` for transcript assembly and quantification.
4.  **Analysis:** Transitioning toward downstream visualization in R/Python.

## 🚀 Research Goals
My long-term goal is to bridge the gap between physical life phenomena and computational implementation, moving toward **whole-cell simulations**. This log documents the foundational bioinformatics skills required to handle large-scale biological data.
